# Bio-AI-Project-2
A simple C++ project.

## Build

### Windows (Visual Studio/MSVC)
```bash
mkdir build
cd build
cmake ..
cd ..
cmake --build build
.\build\Debug\main.exe
```
Alternatively, there is also a build script included that builds and runs the project:
```bash
mkdir build
./build.bat
```

### Linux/macOS (GCC/Clang)
```bash
mkdir build && cd build
cmake ..
make
./main
```
